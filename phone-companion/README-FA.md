# مدیر پروژه روبیکا برای اندروید (نسخه آزمایشی)
یک APK مستقل با شناسه `dev.hooshika.rubikamanager` و بدون مجوز اینترنت.

امکانات: انتخاب پوشه پروژه از طریق فایل‌منیجر خود اندروید، شمارش و فهرست فایل‌ها، کپی بدون حذف اصل CSV/Excel و دیگر فایل‌های پروژه، خروجی ZIP (بدون رمز و با تأیید)، گزارش عددی بدون محتوای خصوصی، نمایش نسخه قابل مشاهده برنامه‌های اصلی و دوم روبیکا، بازکردن آن‌ها و تحویل فایل APK انتخاب‌شده به نصب‌کننده رسمی اندروید.

این برنامه به اطلاعات داخلی صف روبیکا، حساب، پیام‌ها و رمزهای برنامه‌های دیگر دسترسی ندارد؛ پیام ارسال نمی‌کند؛ ChatGPT را مستقیماً به گوشی وصل نمی‌کند. پشتیبان ZIP ممکن است محتوای محرمانه داشته باشد و نباید عمومی شود. شناسه و امضای جداگانه مانع جایگزینی تصادفی نسخه صف روبیکا می‌شود. خروجی CI امضای debug دارد و برای آزمایش و نصب جداگانه است، نه انتشار نهایی.
