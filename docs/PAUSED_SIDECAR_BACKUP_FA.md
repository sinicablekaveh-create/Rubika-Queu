# پشتیبان‌گیری ایمن از صف نسخه دوم روبیکا

**هدف:** حفظ وضعیت صف نسخه نصب‌شده «صف روبیکا • نسخه دوم» بدون حذف برنامه، ارسال پیام یا تغییر داده‌ها. این نسخه آزمایشی با شناسه بسته \`ir.sinicable.rubikaqueue.sidecar\` و کلید امضای موقت ساخته شده است؛ یک APK امضاشده با کلید دیگر نمی‌تواند آن را با حفظ داده‌های داخلی آپدیت کند.

## پشتیبان‌گیری با رضایت صاحب دستگاه

1. **ابتدا ارسال صف را در نسخه دوم متوقف کنید.** از گزارش تشخیصی تأیید کنید «صف فعال: خیر» و بعد از گرفتن پشتیبان، تا تعیین تکلیف مهاجرت صف را دوباره راه نیندازید؛ نسخه پشتیبان می‌تواند در غیر این صورت قدیمی شود.
2. گوشی خود را از طریق USB به کامپیوتر مورداعتماد وصل کنید. Developer options / USB debugging و مجوز اتصال آن کامپیوتر را روی گوشی تأیید کنید. ابزار فقط روی APK قابل دیباگ فعلی با \`run-as\` کار می‌کند؛ اگر دسترسی ممکن نباشد، بدون تغییر گوشی متوقف می‌شود.
3. روی کامپیوتر Android Platform Tools (فرمان \`adb\`)، Python 3 و \`cryptography\` را نصب کنید: \`python -m pip install cryptography\`.
4. از پوشه کد پروژه اجرای \`python scripts/backup_sidecar_queue.py\` را شروع کنید. وقتی صف متوقف است کلمه \`PAUSED\` را وارد کنید، سپس رمز مستقل پشتیبان با دست‌کم ۱۲ کاراکتر را دو بار وارد کنید.
5. فایل رمزگذاری‌شده \`.rqbk\` در مسیر خصوصی \`~/.rubikaqueue-private/queue-backups/\` ذخیره می‌شود؛ بیرون GitHub و بدون نمایش شماره تماس و متن پیام. برای اعتبارسنجی \`python scripts/backup_sidecar_queue.py --verify "PATH_TO_FILE"\` را اجرا کنید. رمز را گم نکنید؛ برای بازکردن پشتیبان لازم است.

ابزار فقط \`files/job.json\` را با فرمان **خواندنی** \`adb exec-out run-as ir.sinicable.rubikaqueue.sidecar cat files/job.json\` می‌گیرد و آن را با AES-256-GCM و کلید مشتق‌شده از رمز از طریق PBKDF2-SHA256 رمزگذاری می‌کند. نشست ورود، Vault، رمز عبور، کلید روبیکا و تاریخچه مستقل برنامه کپی نمی‌شوند. **این نسخه از ابزار، داده‌ها را بازیابی یا وارد برنامه جدید نمی‌کند.**

**قبل از مهاجرت:** باید ابزار واردکردن امن همین نسخه پشتیبان با تأیید دوباره حساب، بررسی ردیف‌های \`sending\` و \`uncertain\` و جلوگیری از ادامه خودکار ارسال ایجاد و تست شود. فایل CSV وضعیت به‌تنهایی جای پشتیبان صف را نمی‌گیرد. تا اجرای موفق آن، هر دو برنامه نصب‌شده را حفظ کنید. برای نسخه‌های پایدار آینده نیز یک کلید امضای جدید، ثابت و تحت مالکیت شما لازم است؛ بازیابی کلید امضای قدیمی مطرح نیست.

هیچ فایل \`.rqbk\` یا رمز آن را در چت یا GitHub قرار ندهید. اگر دسترسی رایانه یا USB ندارید، از حذف یا نصب جایگزین خودداری کنید.
