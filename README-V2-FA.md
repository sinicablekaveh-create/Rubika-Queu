# روبیکا: سه صف مستقل نسخه نهایی 2.0.0 — C++/JNI و HTTPS
- سازگار با نصب به‌روزرسانی v1.8.1 به شرط گواهی امضای یکسان؛ شناسه بسته: ir.sinicable.rubikaqueue.cpp180
- سه حساب شخصی، سه نشست، سه صف مجزا و ارسال پیام متنی به گیرندگان دارای رضایت.
- افزودن گیرنده با Excel، CSV یا شماره دستی؛ شماره دستی فقط برای *صف* ذخیره می‌شود و ارسال را آغاز نمی‌کند.
- تایید رضایت مخاطبان، نمایش پیش‌نمایش و تایید مجدد شروع صف.
- فواصل ارسال 30 تا 3600 ثانیه، توقف/مکث، بازیابی پس از قطع برنامه و جلوگیری از ارسال تکراری نامشخص.
- C++17 JNI در librubikasendcore.so پارامترهای ارسال را کنترل می‌کند؛ ارسال HTTPS و رمزنگاری در Java است.
- فقط سرورهای HTTPS دامنه‌های مجاز rubika.ir/iranlms.ir؛ اعتبارسنجی گواهی سیستم فعال و HTTP مسدود است.
- ارسال عکس از حساب شخصی هنوز پشتیبانی نمی‌شود و رابط صریحاً اعلام می‌کند.
- روش ارتباط حساب شخصی غیررسمی است؛ API عمومی rubika.ir/botapi فقط برای بات‌ها مستند شده است.
- ساخت APK با موفقیت لزوماً به معنای ورود یا ارسال موفق در زمان اجرا نیست.
- هرگز نشست، رمز، کد تأیید یا گواهی امضا را در GitHub منتشر نکنید.
